Varity is The Orchestration Cloud. It turns independent compute into two
products: Varity Cloud for applications, CPU VMs, and GPU workloads, and the
Varity AI Gateway for managed multi-model AI access. These docs cover their
shipped developer interfaces and current limits.

## Start Here

<CardGrid>
  <Card title="Deploy from an AI editor" icon="laptop">
    Add the MCP server to Claude Code, Cursor, Windsurf, or VS Code.

    ```bash
    claude mcp add varity -- npx -y @varity-labs/mcp
    ```

    [Set up MCP](/ai-tools/mcp-server-spec/)
  </Card>
  <Card title="Deploy from the CLI" icon="seti:shell">
    Install `varitykit` and deploy from a supported project folder.

    ```bash
    pipx install varitykit
    varitykit app deploy
    ```

    [Quickstart](/getting-started/quickstart/)
  </Card>
</CardGrid>

## What Varity Supports Today

<Aside type="note" title="Current beta surface">
Source deployments support Node, Python, Go, and static projects. Docker image deployments support public and private Docker or OCI HTTP service images.
</Aside>

**Supported source stacks:** Next.js, React, Vue, Astro, Qwik, Vite SPA, Express, Fastify, NestJS, Koa, Hono, FastAPI, Django, Flask, Go modules, and plain static HTML.

**Supported services:** Postgres with vector extension support, Redis, MongoDB, MySQL, object storage, and model runtime services when detected from your app.

**Not shipped yet:** cron jobs, preview deployments, one click rollback, and managed database backups and restore.
