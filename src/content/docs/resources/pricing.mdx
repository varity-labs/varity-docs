Varity documentation does not maintain a price book. Prices, credits, fees,
catalog availability, and resource profiles can change independently of this
site. A copied value would become a second, discrepancy-causing owner.

## Current Price Sources

Use the source that matches the workload:

| Workload | Current source |
| --- | --- |
| Managed applications and static sites | `GET https://varity.app/api/pricing` or the [Developer Portal](https://developer.store.varity.so/?utm_source=docs&utm_medium=content&utm_campaign=docs-to-portal&utm_content=pricing-portal) quote shown before deploy |
| Pre-deploy application estimate | `GET https://varity.app/api/pricing/estimate` or `varity_cost_calculator` |
| CPU VM or GPU machine | `POST https://varity.app/api/pricing/machine-quote` |
| GPU container | `POST https://varity.app/api/pricing/accelerator-quote` |
| AI Gateway request rates | `GET https://ai.varity.app/v1/models` |
| AI Gateway funding terms | `GET https://ai.varity.app/v1/openapi.json`, field `x-varity-commercial-contract` |

<Aside type="caution" title="Fail closed on missing pricing">
If the live pricing response or workload-bound quote is unavailable, no current
numeric price is available to publish or spend against. Do not fall back to a
number copied from this page, a screenshot, or an earlier quote.
</Aside>

## How Billing Is Shaped

- Application pricing is tied to the selected reserved profile. Read the live
  response for the applicable maximum, proration, storage, replica, and credit
  policy.
- Machine and accelerator prices are bound by a time-limited quote. If the
  quote expires or the requested workload changes, request a new one.
- AI Gateway request rates come from the live model catalog. Funding terms are
  separately published in its OpenAPI commercial-contract block.
- A price shown when a billable action is confirmed is the transactional price
  for that action. Documentation never authorizes a charge.

## Deletion and Billing Closure

Deletion can be asynchronous. An accepted delete request is not proof that
routing, resource release, and billing closure have all converged. Follow the
returned operation or resource state until the billing state is terminal.
